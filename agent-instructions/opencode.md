# OpenCode Instructions

This file supplements the root `AGENTS.md` for OpenCode sessions. The root file,
current experiment record, and approved pipeline design remain authoritative.

## Scope

- OpenCode may perform approved, bounded research tooling, collection-pipeline,
  testing, performance, maintainability, and code-review work.
- Do not independently choose or change the production data source, retention
  policy, source-rights interpretation, final trend score, product output,
  cloud provider, or public API contract. Report the concrete decision boundary.
- Treat notebooks and experimental branches as evidence, not automatically as
  production contracts.

## Workflow

- Keep changes attributable to one stated question and preserve unrelated work.
- Read the relevant source, test, and current experiment record before editing.
- Explain material data or algorithm choices, but do not turn routine changes
  into a tutorial.
- Use OpenCode-native capabilities only. Do not imitate or claim Codex-only
  Skills, custom agents, hooks, model roles, or tool results.
- Keep provider credentials, personal model configuration, and authentication
  out of committed project files unless the user explicitly approves them.
- Verify the smallest relevant behavior and report untested external or runtime
  assumptions plainly.
